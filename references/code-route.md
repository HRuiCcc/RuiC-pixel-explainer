# B · 没有图片生成能力

保留已有Canvas/React流程，使用升级后的独立代码人物。不要要求使用者先安装生图模型，不用简单全身放大替代半身，也不把代码图称作img2生成图。

## 已升级的角色函数

assets/cinematic-template/scene.mjs 中 frontActor(c,x,y,s,t,skin,speaking) 保持旧参数，但现在绘制独立32×35半身：大头、肩膀、胸部、袖子、手臂、连续腰线，没有腿脚。

sideActor(c,x,foot,s,t,skin,walking) 保持boolean walking兼容，额外支持 idle / walk / celebrate 字符串。它现在是24×31正面或轻3/4的Q版行动轮廓，头约65%高度；不再绘制凸出的侧鼻。脚底按foot锚定，动作吃时间t。

肤色约3层、眼白与瞳孔为方块、小嘴、少量腮红。**脸中部保持皮肤平面，不画鼻梁、鼻子点、鼻尖高光或向外突出的鼻轮廓**。无参考时可独立设计新角色；有参考时用可辨认的帽、发、眼、服装和配件尽量复现身份，不承诺像素完全一致。

## 可配置但不等于完整新设计

旧actor色表继续有效。可选字段：

```json
{
  "hairStyle": "bob",
  "headwear": "cap",
  "headwearColor": "#293536",
  "headwearLight": "#48585a",
  "headwearAccent": "#b9c2a4",
  "eye": "#984352",
  "eyeLeft": "#4d7fa3",
  "eyeRight": "#984352",
  "eyePatch": "right"
}
```

hairStyle支持bob / long / short，headwear支持none / cap / beret；左右眼与眼罩可分别设定。需要特别头盔、猫耳、裙装或其它参考特征时，扩展对应绘制函数，不把换色当完整重设计。不要全局改掉旧React工程已验收的角色；本次新期选择这套角色。

## 场景仍然要对应角色

没有生图只是人物生成方法不同，场景、道具、HUD、字幕和语义事件不降级。服装与气质决定空间，动作说明知识点；用组件让人物关闭、拿取、标记、核对、获得，而不是只走路。背景继续保持简单粗像素和明确光源，不通过加密纹理解决单调。

## 必查

大人物必须可看出半身和腰线，小人完整帽发脸与短身体可辨认；站立、走路与庆祝身份连续；帽子和眼罩方向正确；面板避开人物整条行走路径，不是只避开初始站位。先截开头、走路中段、终点三个时刻，再逐帧出片。配音后端与音色速度仍按本次使用者配置，不由角色路线写死。
