# A · 有图片生成能力

本路线用于宿主能调用img2、内置imagegen或使用者已经提供且授权的生图后端时。调用当前已有能力，不新增SDK、模型下载或密钥流程；遵守该能力的透明背景与本地图片访问规则。

## 人物资源是两套，不是一张全身图的两个缩放

1. 有参考图时先看图，记录身份特征：帽/头盔、头发、眼色、眼罩左右、衣服色块和配饰。多角色参考分角色生成，不在同一图集中混角色。没有参考时先独立设计角色。
2. 每角色生成**4×4透明小人物动作表**，16格。动作序可用：第一行站立/说话/眨眼/指向；第二行向右走四帧；第三行向左走四帧；第四行思考/拿物/庆祝/持物。按照本期需要调整动作并记录帧序，不能把任意一格猜成走路。
3. 单独生成**半身表情图**，建议2×2四格：中性、说话、眨眼、手势。参考用户原图与已生成的小人表，锁住脸、帽饰、眼色和衣服。从帽顶到腰线，有肩臂胸部与连续衣服下摆；不出现裤腿、脚或中央两块像脚的浅色形状。
4. 先检查身份、脸、鼻子、完整轮廓、格间透明边界、同组尺度和四种表情。生成出全身而非半身时，定向修改颈部以下，保留脸与头饰；不能靠最后在桌后遮脚掩盖错误资源。不能在PNG上用代码补鼻子或重新画脸。

## 提示词的有效约束

小人强调大头短身体、参考中的厚黑阶梯轮廓、少量方形色块、有限色板。半身强调明显肩膀/袖子/手臂与直的腰部衣服下摆。脸只有参考眼睛、小嘴与少量腮红，**无鼻梁、突出侧鼻、鼻尖高光和中心鼻影**。不画渐变皮肤、发丝、虹膜闪光、密集衣服缝线和柔焦。

图集中每格只放同一角色，留足透明边界，不带地面、阴影、背景、编号、文字和网格线。头盔、长发、手势与脚不能碰格边。语义格序统一，但生成图尺寸不必恰好是1024或能被4整除，注册时读实际alpha间隔。

不强制镜像非对称角色：眼罩、胸章和配件必须留在角色本来的一侧，向左/右的动作可采用轻3/4或正面行走，避免转向时身份错位。

## 注册与接入

脚本只做alpha定位、裁切、统一最近邻缩放和锚点对齐，保留裁区RGBA，不负责绘图或抠白底。

```bash
python3 <技能目录>/scripts/register_actor_sheet.py --sheet mini.png --grid 4x4 --canvas 256 --baseline 240 --out <工程>/assets/sprites
python3 <技能目录>/scripts/register_actor_sheet.py --sheet half-body.png --grid 2x2 --canvas 512 --baseline 500 --out <工程>/assets/bust
```

默认alpha>128用于找到主体，外围保留3px安全边界；远离角色的alpha=1散点不决定大小。每组只用一个缩放系数，不逐帧缩放来伪装生成的一致性。没有真alpha、透明间隔不足、主体尺度差距过大时明确失败，重新生成；不按尺寸等分硬切帽子或脚。核对manifest中的裁区和锚点。

`assets/imagegen-template/` 是**静音资产检查页与SpriteActor适配器**，不是成品场景。不带角色PNG、口播或主题，缺图会报错。接法见其 [INTEGRATION.md](../assets/imagegen-template/INTEGRATION.md)。复制cinematic-template的背景、组件、字幕和播放器到工程，按角色重新设计场景，并把旧画脸函数调用替换为PNG绘制。加载16小人＋4半身成功后，才发布__player和移除loading。

大人调用portrait，按腰线放在桌边或讲台前；小人调用mini，按脚底放在地面或台阶上。所有状态选择吃时间t。背景、道具、人物、前景与HUD独立，不把整张截图当背景电影重放。

## 最新案例的可迁移部分

暖色排练室用音箱、吉他、乐句条、节拍器和拼接反馈；冷色创作工坊用月窗、画板、色块、修改动作与灵感灯。下一角色重选空间和可见动作，不能只替換PNG继续同一段路。大人是独立半身、小人是4×4动作表、无突出鼻子、完整帽发脸不被组件盖住，这些是共同规范。

## 生图受限

可读图不等于可生成图。工具不可用时走B，或复用用户已有有效PNG并如实记录来源；不要声称成功调用img2。用户坚持某个不可用生图后端时，完成可独立推进的部分，指出缺失能力，不以代码图冒充该后端产物。
