# 像素游戏讲解片 · 视觉 DNA

> 这条流派的皮：**16-bit 像素 RPG 世界在讲知识**。参考片：《刻意练习》＝"神"的武器（一只索尔）、
> 《被讨厌的勇气》《纳瓦尔宝典》《从0到1》大疆篇。视觉规格的权威源是母提示词 v1.0
> （`~/Desktop/zcode/ai-explain-game/prompt/AI知识讲解·像素游戏演示台-母提示词.md`）；本文件是它的速查。
>
> **像素皮不是滤镜，是骨骼**：所有元素都有像素块边缘、硬边框、明确光源。

## 1. 银幕与像素

| 项 | 规格 |
|---|---|
| 设计分辨率 | 16:9，逻辑画布 **320×180** → 内部缓冲 640×360 → 显示层最近邻放大（`image-rendering: pixelated`）|
| 成片分辨率 | 1920×1080（= 艺术格 ×6，整数倍，像素不畸变）；设计稿 1280×720 = ×4 |
| 像素块大小 | 随推近变大：参考片在 1080p 上约 6–16px |
| 帧率 | 30fps（这条流派的原生节奏；逐帧导出时按毫秒定点） |
| 相机 | `{x, y, zoom}`，zoom 0.75–3.0；一段运镜 1.2–2.5s，**动完停稳** |

## 2. 三件套招牌（缺一件就不像这条流派）

1. **顶部章节轨**：全宽等分（一章一格），格外细竖线；未到章节灰字，**当前章亮字（近白）**，不加下划线；字号 ≈ 屏宽/72。
2. **底部字幕**：单行、居中、粗圆体 + 深色描边（描边宽 ≈ 字号/8）；**一行 ≤22 个汉字**，超了拆两句；**永远不折行**；底缘距画面下沿 ≥8% 高。
   三个层次顺序固定：**地点卡**（字幕上方小胶囊，如"像素讲堂 · 第一关 · 数据海洋"）→ **字幕本体** → **关键词高亮**（每句只高亮 1 个词，橙色 `#ffb347`，用 `[[ ]]` 标记）。
3. **右上角署名**：`署名 · 作品/主题`（例 `RuiC · AI 知识课`），灰字小一号。

## 4. 字体

- 场景内一切 UI / 标签 / 面板 / 数字：**Fusion Pixel Font 12px（缝合像素字体，OFL-1.1）**，
  `font-family: "Fusion Pixel 12px Proportional Simplified Chinese"`；**只允许整数倍字号**（12/24/36/48），
  16px 这种非整数倍会把像素拉花。字体文件随技能自包含（`assets/fonts/`），或从 `~/Desktop/zcode/ai-explain-game/game/public/fonts/` 拷。
- **字幕用系统粗体**（PingFang SC 700）+ 描边，不做像素化 —— 字幕是"现代字幕"，场景才是像素。

## 5. 光源（最容易被做丑的地方）

- 每个场景必须有**一个主光源**（街灯 / 台灯 / 屏幕光 / 火光）：锥形或圆形光晕 + 暗角（vignette）。
- 主角（像素小人）**站在光里**；讲重点时给主角或重点物一圈柔光（"高光时刻"）。
- **禁止无光平铺**：任何"全画面一样亮"的场景判不合格。

## 6. 常驻 HUD（"游戏感"的来源，每期按需上）

这些是让片子像"游戏"而不是"PPT"的关键，挑 1~2 个用：
左上**玩家状态面板**（头像 / 等级 / 金钱 / 装备栏"新手剑"）· **对 +1 错 −2** 规则条 · **第 N 次**计数 · **计时器** ·
**关卡开幕牌**（双段式：金底"第 N 关" + 黑底关名）· **通关徽章** · 地图节点（当前关脉冲 / 已过关亮灯 / 未解锁灰）。

## 7. 叙事骨架（五段式，原创照这个填）

1. **数字钩子**（1 场景，8–12s）：一个真实可查的反差数字（参考片用 `10 × 365 = 3650`）。
2. **上地图**（1 场景，6–10s）：关卡地图 + 节点 + 虚线路径 + 小人站起点，预告几关。
3. **闯关主体**（每关 2–3 场景）：每关都是 **它是什么 → 为什么有用 → 怎么起作用**，每关一个**可画的贯穿比喻**。
4. **通关**（1 场景，6–10s）：地图全亮 + 徽章 + 打勾清单（浓缩成"三件事"）。
5. **金句收尾**（1 场景，6–10s）：一句能被复述的话 + 安静定格；**结尾必须单独设计**，不许用中段套路。

禁用：过渡话（"接下来我们讲…"）、负向钩子（"你不知道就完了"）、口头禅空话（"非常非常重要"）。

元素与字幕带 ≥24px 安全距离；元素不许压主角脸。

## 9. 硬规矩（违反即打回）

1. 一句口播一个场景（6–14s），别切快 —— 30 秒 8–10 刀是上限。
2. 动画与元素出场锚定口播；不许一口气演完就静止。
3. **镜头动完要停稳**，不许整段慢漂移（人会晕）。
4. 画面三忌：**不空**（≥2s 无变化不行）、**不挤**（同屏主元素 ≤1）、**要丝滑**（场景间硬切，场景内缓动）。
5. 结尾单独设计，别一直停住；留一个"呼吸"的定格。
6. 主角每关至少出现一次，不许只剩 UI 空转。
7. 字幕永远单行 ≤22 汉字；每句只高亮 1 个橙色关键词。
8. 画面不出现网址后缀（露域名时去掉 `.com`）；不出现金额数字；不出现"爬取"字样。
9. 用词替换：免费→白嫖、token→代币、供应商→大模型；不出现 Claude / Codex / GPT 等具体产品名（讲 AI 常识用"大模型"）。
10. 数字、术语、年份、人名必须有出处；估算值画面标注"示意"。
11. 离线可跑（不依赖 CDN，字体图标全本地）；可暂停、可拖动进度、可倍速；**纯观看不动手也能播完**（交互点静置 3 秒自动选默认项）。
12. **样式每期必须换款**（他拍板：多账号共用素材，连续几期长一个样会被看出同源）—— 至少换顶部标题条与底部进度/轨道的款。

## 10. 交付习惯（这条线的门）

- **门一**：先交「事实表 + 关卡表 + 分镜表」（含每句字幕全文 ≤22 字），等他点头；**确认前不写代码不配音**。
- **门二**：跑起来先把**每个场景的截图**发他看，再谈"完成"。
- 换风格先出「开头 + 1~2 片段」样片。
- 交付给绝对路径；成片默认落 `~/Desktop/zcode/`（只有他明说才放桌面）。
