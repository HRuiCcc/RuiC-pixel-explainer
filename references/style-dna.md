# 粗像素视觉定标

以本次《刻意练习》参考片与用户“场景、人物都不要这么精细”的反馈为依据。主入口见 SKILL.md；代码接法见 cinematic-profile.md。

## 三种分辨率不要混成一种

| 层 | 1080p 中的建议尺度 | 用途 |
|---|---|---|
| 大人物 | 主体约 400–620 px 高；脸约 280–400 px；色块约 12–20 px | 情绪与开场 |
| 小人物 | 主体约 130–220 px 高；色块约 4–8 px | 在世界里演步骤 |
| 环境 | 建筑约 60–180 px 的大体块；少量细线约 2–8 px | 深度、位置和质感 |
| 字幕 / HUD | 原生 1920×1080 单独绘制 | 跟世界镜头解耦 |
| 柔光 / 暗角 | 原生画布低对比渐变 | 确立光源，脸不柔焦 |

这些是视觉标尺，不是每次都相同的常数。参考片的大人物不是 14×21 小精灵被放大；旧模板恰好在这里丢失了眼睛、眉毛和嘴的层次。

## 人物

- 脸约 18–28 格宽、20–24 格高，独立白眼睛、瞳孔、眉毛与嘴；头占人物高度约 55%–70%。
- 头发 2–3 个主要块面，肤色 3 层足够，一格腮红可选。不要细发丝、渐变脸、虹膜反光和过多衣服缝线。
- 手可与身体略分离，以方块手势强化讲解；有肩膀和衣领，身体别剩窄条。
- 小人物重画行动轮廓，而不是平均缩小大人物全部细节。发型、衣色、配件保持身份连续；站立、侧身和走路两帧足够短样片。
- 新人物改变轮廓、发型或服装结构，不把换色和加耳机视为完整新人物设计。

## 场景密度

两三个识别物就能定地点：修理铺＝桌椅＋灯＋钟；记忆关卡＝书＋路＋锁门。大部分处在暗部，纹理只帮助辨认材质。不要把空处填满图腾、齿轮、密集书架与花纹。

墙砖不是满屏粗棋盘，采用低对比短横线、错缝和少量面板。主角身后的区域更安静，脸的对比高于背景。

## 光与色

暖主光约 #d8c58c；外围近黑棕或灰绿。皮肤可用 #edc49c / #ddb18c / #bf926c；轮廓 #19221e。金边和关键词 #cfab57 / #d9a13e；青绿只用于反馈或路径。这是示例配方，角色服装与地点可按主题改变。

聚光锥是淡的半透明面，灯口小范围柔光。避免棋盘发光环抢脸的焦点。前景桌边挡腿，人物在中、环境在后、字幕在最后；别把道具都封装成网页卡片。

## 字幕与字体

本参考型配置采用本地 Fusion Pixel，字幕通常 60–72 px，场景标签常用 24–36 px；实际按画布与文字量定。必须用实际中文文本预载分包字体：

```js
await document.fonts.load('72px "Fusion Pixel 12px Proportional Simplified Chinese"', fullChineseText);
await document.fonts.ready;
```

不传第二个 text 参数只触发拉丁字形，首帧可能临时使用系统字。保持单行居中、底部暗区；纸白外描边、暗内描边、纸白填充与一个金色关键词。超宽按语义拆拍，不强行缩小。

## HUD 与包装

大人物开局可以无章节轨，小人物入关后再出现导航、署名、计数或反馈。不是每镜都需导航＋地点卡＋进度＋状态卡。

用户要求参考感觉时保持这些稳定特征；只有用户明确要求不同账号或系列换款才改变包装，不把每期必须换款当作参考模式的硬门。
