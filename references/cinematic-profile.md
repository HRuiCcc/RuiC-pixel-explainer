# B · 原创粗像素代码样板

用于没有生图能力或用户选择纯代码时的大人物开场、小人物演示，保留旧流程并升级角色比例。A 生图路线见 [imagegen-route.md](imagegen-route.md)；它可复用本模板的背景、组件、字幕和播放器，以 PNG 替换角色函数。不要用恢复帧代替原创场景。

## 自包含模板

assets/cinematic-template/ 中：scene.mjs 独立绘制人物、后景、道具、前景、灯光、HUD、字幕；episode.json 存主题、角色参数、镜头切点、说话区间和字幕；index.html 暴露旧导出器兼容的 window.__player.set(ms) / total；assets/fonts/ 为本地 Fusion Pixel 与许可证；assets/voice.wav 是 20 秒示范配音，新主题必须替换；serve.py 启本机 HTTP 服务，支持音频 byte-range。

先复制到项目再改。角色函数与可选参数见 [code-route.md](code-route.md)。JSON 改色不是自动设计新角色；模板字段不足以表现新轮廓时，扩展 frontActor、sideActor；新场景修改 buildBackgrounds 与动作代码。

## 20 秒示范结构

| 时间 | 镜头 | 语义拍 | 动作 |
|---|---|---|---|
| 0–10s | 修理铺，半身人物 | 笔记越来越多，能想起的没几个 | 1.1 秒轻推停稳；讲话、眨眼；笔记堆叠；问号面板；桌边衔接腰线 |
| 10–20s | 记忆廊道，小人物 | 提取而非只存入，合上笔记讲一遍 | 思考问号、拿钥匙、走向门、开门和反馈 |

这是用于检查引擎的旧示例剧情。B 中人物、场景和字幕都是代码绘制；默认角色已改成独立半身与大头平面脸小人，均无突出鼻子。新主题重新匹配人物与空间，不必总是修理铺、钥匙和开门。

## 内容组件

`components.mjs` 提供资料卡、物品栏、书页开合、检索面板、答题与答案对照、卡点旗、即时反馈条、奖励徽章。`scene.mjs` 的增强层在 episode 配置存在 visualBeats 时启用，原配置继续使用原先简单样板；不要通过增加背景纹理来解决讲解单调。具体 API 见 teaching-components.md。

## 时间轴与复用

CinematicScene.draw(canvas, ms) 是纯时间函数，画布恒为 1920×1080；后景预画一次，人物和道具每帧独立画；表面纹理固定随机种子。

大人物主格约 32×35，头占约 23 行，下部是肩胸、袖子、手臂和连续腰线，没有腿；小人物为 24×31 正面或轻 3/4 的大头短身，支持站立、走路和庆祝，不绘突出鼻子。美术格是对象自身尺度，不把文字与背景都压进同一张 320×180。

说话只在 episode.voice 区间开启，眨眼、脚步和道具运动都吃 ms，出片通过 __player.set(ms)，不录屏凑帧。

需要选择题、评分与完整关卡菜单时，可把新绘制函数接进旧 React Stage，仅对新一期选择它；保留原有已验收的期。

## 声音

沿用使用者自己提供的 HTTP / 本地 TTS 后端或成品音轨，接法见 [pipeline.md](pipeline.md) 第 5 节。先量真实时长再排时间轴。模板内 voice.wav 是旧示范音轨，新主题必须替换；它不定义本技能的音色与语速。

voice_track.py 默认拒绝段落重叠，只有经明确需要叠声才传 --allow-overlap。不要裁掉句尾来满足预算。

## 验证重点

检查半身肩臂与腰线、小人大头短身、平面无鼻脸、帽发脸完整、面板不遮挡行走路径、字幕字形与安全区；同一时刻重截应字节一致，确定性失败就停；ffprobe 核对时长、帧数、帧率和音轨。音频补静音到画面长度，不用 -shortest 吃尾巴。
